# Security policy

## Supported versions

Only the latest `main` is supported.

## Reporting a vulnerability

Report vulnerabilities only through GitHub's private vulnerability reporting: this repository's **Security** tab →
**Report a vulnerability**. Please do not report them in public; there is no e-mail address for reports.

A useful report names the affected part (the kit, the records Worker or its admin page), the steps to reproduce it and
the impact.

There is no bug bounty.
